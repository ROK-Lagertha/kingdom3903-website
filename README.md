# 3903 | The Citadel

Minimal landing page for kingdom3903.com, featuring only the official Citadel logo.

## Files

- `index.html` — responsive landing page
- `assets/citadel-logo.png` — transparent logo artwork

## Deployment

Replace the existing website files in the `kingdom3903-website` repository with the contents of this package. Keep any Cloudflare configuration files required by the existing deployment. The website is static and does not require a build step.

The BattleTrack and FlagFiller Registry applications are separate deployments and are not changed by this package.
